Privacy Policy

Last updated: October 3, 2026

Travel Calendar Sync is a personal tool used only by its developer. This policy describes what Google user data it accesses and how that data is handled.

Data accessed

  • Gmail (read-only): the app searches for booking confirmation emails from airlines, hotels, and travel agencies, and reads those messages and their PDF attachments (such as e-tickets). It cannot send, modify, or delete email.
  • Google Calendar: the app creates, updates, and deletes events on the developer's own travel calendars.

How data is used

Booking details such as flight numbers, dates, hotel names, and confirmation numbers are extracted from these emails solely to create and maintain calendar events. To extract these details, the content of matching emails is sent to Anthropic's Claude API for processing. Data is not used for advertising, is not sold, and is not shared with anyone else.

Storage

The extracted booking details, the IDs of processed messages, and processing logs are kept in a private database controlled by the developer, so that each booking is added to the calendar only once. Full email bodies are not stored.

Google API Services User Data Policy

Travel Calendar Sync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
